# StockFlow

StockFlow is a Flutter app for grocery stores and retail teams to manage inventory, replenishment, and store operations from a simple mobile interface.

## Features

- Clean login screen for store staff
- Mobile-first design for daily stock management
- Ready-to-extend app structure for inventory workflows

## Getting Started

1. Install Flutter.
2. Run `flutter pub get` in the project root.
3. Launch the app with `flutter run`.

## Validation

This project includes widget tests covering the primary login screen flow.
